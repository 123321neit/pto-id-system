# Registry Module

Purpose: derived registry projection boundary.

Owns:

- registry projection contracts;
- presentation-only override boundaries;
- registry read-boundary vocabulary for future package and UI workflows.

Forbidden responsibilities:

- source-of-truth ownership for document, evidence, company, object, or scheme
  facts;
- hiding domain errors;
- mutating typed documents or file-backed evidence;
- package snapshots or generated artifact storage;
- projection builders or persistence in this skeleton.

Current status: architecture skeleton only.
