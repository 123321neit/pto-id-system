# AI Module

Purpose: future AI/OCR review boundary for proposals, citations, and findings.

Owns:

- proposal and finding boundaries;
- future review-state contracts;
- human-confirmation boundary for AI/OCR suggestions.

Forbidden responsibilities:

- autonomous source mutations;
- confirmation of document, evidence, registry, or package data;
- validation suppression;
- provider SDK imports or AI provider implementation;
- queue jobs or file processing.

Current status: architecture skeleton only.
