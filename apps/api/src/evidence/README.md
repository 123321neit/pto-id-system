# Evidence Module

Purpose: file-backed evidence boundary.

Owns:

- certificate boundary;
- executive scheme boundary;
- evidence metadata and provenance contracts;
- proof-file requirement boundary for future documents, registry, and packages.

Forbidden responsibilities:

- generated package ownership;
- source document payloads or revisions;
- registry projection ownership;
- storage provider implementation;
- uploads, repositories, or evidence behavior in this skeleton.

Current status: architecture skeleton only.
